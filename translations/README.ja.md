# NovaCut AI Studio (日本語)

[English](../README.md) • [فارسی](../README.fa.md)

**Adobe Premiere Pro 向け万能 AI 自動化ブリッジ。**  
**ChatGPT、Google Gemini、xAI Grok、Claude、Cursor、Windsurf** から Premiere Pro を直接操作できます。

---

> **プロジェクトの起源と謝辞 (Attribution):**  
> NovaCut AI Studio は、オープンソースプロジェクト [hetpatel-11/adobe_premiere_pro_mcp](https://github.com/hetpatel-11/adobe_premiere_pro_mcp) を **ベースに、徹底した最適化・UI刷新・バグ修正を行った進化版** です。  
> **NovaCut の主な進化ポイント:**
> - **全 AI モデル対応:** Claude 専用という制約を撤廃し、ChatGPT、Gemini、Grok、Cursor など主要モデルに全対応。
> - **Windows 1クリック簡単インストーラー:** 専用アイコンと最新 UI を備えた `NovaCut-Setup.exe` により、コマンド不要で即座に導入可能。
> - **Capzo AI 自動字幕連携:** 音声認識から単語単位のテロップ生成、Premiere タイムラインへの自動配置までをワンクリックで実現。
> - **極上のミニマル UI:** 黒曜石を基調とした美しいダークテーマ、リアルタイムステータスレーダー、ペルシャ語（RTL）/ 英語の完全サポート。
> - **既知のバグを完全解消:** プリセットダイアログのフリーズ、ツール ID の不一致、stdio 通信のクラッシュを解消。

---

## 3ステップ・クイックスタート

1. **1クリックインストール:** Windows では **`NovaCut-Setup.exe`** をダブルクリックして実行（macOS では `scripts/install-macos.sh`）。  
   *Premiere 拡張機能、レジストリ、各種 AI アプリの設定がすべて自動で行われます。*
2. **Premiere Pro で開く:**
   ```text
   ウィンドウ (Window)  ──>  エクステンション (Extensions)  ──>  NovaCut AI Studio
   ```
3. **AI で編集を開始:** ChatGPT や Claude に指示を出します：  
   > *「素材フォルダ内の動画をプロジェクトに取り込んで、4K のタイムラインを作成して。」*
