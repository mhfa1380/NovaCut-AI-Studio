# 🎬 NovaCut AI Studio (Dansk)

[English](../README.md) • [فارسی](../README.fa.md)

**Universel AI-automatiseringsbro til Adobe Premiere Pro.**  
Styr Premiere Pro via **ChatGPT, Google Gemini, xAI Grok, Claude, Cursor og Windsurf**.

---

> 💡 **Oprindelse & Anerkendelse (Attribution):**  
> NovaCut AI Studio er en **optimeret, forbedret og fejlfri version inspireret af** open source-projektet [Adobe_Premiere_Pro_MCP af hetpatel-11](https://github.com/hetpatel-11/adobe_premiere_pro_mcp).  
> **Nøgleforbedringer i NovaCut:**
> - **Universel AI-understøttelse:** Virker problemfrit med ChatGPT, Gemini, Grok, Claude og Cursor.
> - **1-Klik Windows Installationsprogram:** `NovaCut-Setup.exe` med moderne UI og indbygget ikon — ingen terminalkommandoer nødvendige.
> - **Capzo AI Undertekster:** Automatisk tale-til-tekst og 1-klik synkronisering direkte på tidslinjen.
> - **Minimalistisk Luksus UI:** Elegant mørkt Obsidian-tema med live-statusradar og tosproget support.
> - **Fuldstændig Fejlrettelse:** Løsning på forudindstillede dialogfrysninger, værktøjs-ID-fejl og stdio-nedbrud.

---

## ⚡ Hurtig Start i 3 Trin

1. **1-Klik Installation:** Kør **`NovaCut-Setup.exe`** på Windows (eller `scripts/install-macos.sh` på Mac).
2. **Åbn i Premiere Pro:**
   ```text
   Vindue  ──>  Udvidelser  ──>  NovaCut AI Studio
   ```
3. **Rediger med AI:** Bed ChatGPT eller Claude om at redigere din tidslinje!
