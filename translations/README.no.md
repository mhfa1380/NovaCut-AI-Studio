# 🎬 NovaCut AI Studio (Norsk)

[English](../README.md) • [فارسی](../README.fa.md)

**Universell AI-automatiseringsbro for Adobe Premiere Pro.**  
Styr Premiere Pro med **ChatGPT, Google Gemini, xAI Grok, Claude, Cursor og Windsurf**.

---

> 💡 **Opprinnelse & Kilde (Attribution):**  
> NovaCut AI Studio er en **optimalisert, forbedret og feilfri utgave inspirert av** åpen kildekode-prosjektet [Adobe_Premiere_Pro_MCP av hetpatel-11](https://github.com/hetpatel-11/adobe_premiere_pro_mcp).  
> **Viktige forbedringer:**
> - **Universell AI-støtte:** Fungerer direkte med ChatGPT, Gemini, Grok, Claude og Cursor.
> - **1-Klikk Windows Installasjon:** `NovaCut-Setup.exe` med grafisk grensesnitt og eget ikon.
> - **Capzo AI Undertekster:** Automatisk tale-til-tekst og direkte synkronisering til tidslinjen.
> - **Minimalistisk Luksus-UI:** Elegant mørkt Obsidian-tema med sanntidsstatus.
> - **Feilrettinger:** Løst problemer med forhåndsinnstillinger, ID-feil og stdio-krasj.

---

## ⚡ Hurtigstart i 3 Trinn

1. **Installer med 1 klikk:** Kjør **`NovaCut-Setup.exe`** på Windows (eller `scripts/install-macos.sh` på Mac).
2. **Åpne i Premiere Pro:**
   ```text
   Vindu  ──>  Utvidelser  ──>  NovaCut AI Studio
   ```
3. **Rediger med AI:** Åpne ChatGPT eller Claude og gi instruksjoner på vanlig språk!
